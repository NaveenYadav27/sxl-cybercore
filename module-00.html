02 · HARDWARE ACCELERATION

Enabling CPU Virtualization (Intel VT-x / AMD-V)

Hardware virtualization allows your host processor to execute guest operating system instructions directly at native hardware speeds. Without it, 64-bit VMs will fail to start.

01

Check Virtualization Status in Windows

Press Ctrl + Shift + Esc to open Task Manager. Go to Performance tab > CPU. Look for Virtualization: Enabled.

PS C:\> Get-CimInstance -ClassName Win32_Processor | Select-Object Name, VirtualizationFirmwareEnabled Name VirtualizationFirmwareEnabled ---- ----------------------------- Intel(R) Core(TM) i7-13700H CPU @ 2.40GHz True
02

If Disabled: Enable in BIOS/UEFI Settings

Reboot your computer and enter BIOS setup by repeatedly pressing the manufacturer key:

  • Dell / Alienware: Press F2 or F12
  • HP: Press F10 or Esc
  • Lenovo / ThinkPad: Press F1 or Enter
  • ASUS / MSI / Gigabyte: Press Del or F2
Navigate to: Advanced CPU Configuration > Enable Intel Virtualization Technology (VT-x) or SVM Mode (AMD-V) > Save & Exit (F10).

08 · LAB ISOLATION ARCHITECTURE

Understanding VirtualBox Network Modes

Configuring the right network adapter mode prevents accidental scanning of your home WiFi while ensuring lab connectivity.

Network Mode VM Can Access Internet? VM Can Access Host? Other VMs Can Access? Primary Use Case
NAT (Default) ✓ Yes ✗ Isolated ✗ Isolated Single VM browsing and package updates (apt update)
NAT Network ✓ Yes ✗ Isolated ✓ Yes (Shared LAN) Multi-VM training labs where VMs must talk to each other
Host-Only Adapter ✗ No ✓ Yes (Virtual Interface) ✓ Yes (Host-only subnet) Isolated malware analysis and local SSH management
Bridged Adapter ✓ Yes ✓ Full Access ✓ Visible on Home LAN ⚠ CAUTION: VM appears directly on your physical home router
Internal Network ✗ No ✗ No ✓ VMs on same internal net 100% air-gapped exploit validation and testing
09 · PREREQUISITE ASSESSMENTS

Knowledge Checkpoints: Prerequisite Validation

Confirm your understanding of the lab architecture before advancing.

CHECKPOINT 01 · VIRTUALIZATION
When attempting to start a 64-bit Kali VM in VirtualBox, you receive an error: "VT-x/AMD-V hardware acceleration is not available". What is the required resolution?
Explanation: 64-bit guest operating systems require CPU hardware virtualization extensions (VT-x/AMD-V) to be toggled to Enabled in the motherboard BIOS/UEFI.
CHECKPOINT 02 · NETWORK ISOLATION
Which VirtualBox network mode creates an isolated virtual subnet where guest VMs can communicate with each other AND reach the Internet, without exposing ports to your physical home WiFi network?
Explanation: NAT Network provides an isolated virtual router that lets VMs talk to each other on a private subnet while sharing outbound NAT internet access without exposing VMs to the physical LAN.
